## 📊 What's Included in Every Post

Each social media post includes three core components:

### 1. Caption ✍️
- Brand voice aligned
- Engagement-optimized (questions, CTAs, storytelling)
- Platform-aware length and formatting
- Emoji integration (if brand-appropriate)
- Story hook in first line

### 2. Hashtags #
- 10+ relevant hashtags per post
- Mix of branded, niche, and trending tags
- Engagement-focused tags
- Discoverability optimized
- Not over-saturated (avoiding 1M+ use tags unless appropriate)

### 3. Image Description 🖼️
- Detailed visual description for designer/photographer
- Brand colors and style specified
- Composition guidance
- Mood and tone notes
- Platform-specific sizing notes
